Introduction

Base URL: http://localhost

This documentation aims to provide all the information you need to work with our API.

As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile). You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).

Authenticating requests

This API is not authenticated.

Endpoints

POST api/auth/register

Example request:
curl --request POST \
    "http://localhost/api/auth/register" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"name\": \"mmchhpezipdjzlsvorllvm\",
    \"email\": \"bmetz@example.org\",
    \"username\": \"fujkxzzs\",
    \"language_id\": 16,
    \"password\": \"h|f4kH$x*8D\",
    \"password_confirmation\": \"ayttsqfjqfydkreveoqa\"
}"

const url = new URL(
    "http://localhost/api/auth/register"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "name": "mmchhpezipdjzlsvorllvm",
    "email": "bmetz@example.org",
    "username": "fujkxzzs",
    "language_id": 16,
    "password": "h|f4kH$x*8D",
    "password_confirmation": "ayttsqfjqfydkreveoqa"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

POST api/auth/register

Headers

Content-Type      

Example: application/json

Accept      

Example: application/json

Body Parameters

name   string   

Must not be greater than 50 characters. Example: mmchhpezipdjzlsvorllvm

email   string   

Must be a valid email address. Must not be greater than 255 characters. Example: bmetz@example.org

username   string   

Must not be greater than 255 characters. Example: fujkxzzs

language_id   number   

Must not be greater than 255. Example: 16

password   string   

Must match the regex /^(?=.[A-Za-z])(?=.\d)(?=.[@$!%#?&])[A-Za-z\d@$!%#?&]+$/. Must be at least 8 characters. Must not be greater than 32 characters. Example: `h|f4kH$x8D`

password_confirmation   string   

Must match the regex /^(?=.[A-Za-z])(?=.\d)(?=.[@$!%#?&])[A-Za-z\d@$!%*#?&]+$/. Must be at least 8 characters. Must not be greater than 32 characters. Example: ayttsqfjqfydkreveoqa
